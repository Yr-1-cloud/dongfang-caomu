# 07 详细设计说明书

## 7.1 ETL 清洗（com/tcm/etl/clean.py）
1. 分批读源表（按 fid 游标，避免一次拉 3.7 万条 longtext）
2. 过滤 `state=1 AND isDel=0`
3. 去 HTML 标签 → `html.unescape` → 压缩空白
4. 按 `<p class="drug xxx"><span class="fieldname">标签</span>` 提取段落
5. 兜底：`【标签】正文` 分段（偏方表无 class 结构）
6. 拼 `content`（每行"标签：文本"），取功能主治作 `summary`
7. 批量写入，`ON DUPLICATE KEY UPDATE` 幂等
8. 输出清洗报告（输入/过滤/入库）

## 7.2 切片与向量化（com/tcm/rag/embedding.py）
- 切片：`content` 一行一段，天然语义边界，一段一个 chunk，文本拼 `标题｜标签：文本`
- 编码：攒 64 段一批 `model.encode(..., normalize_embeddings=True)`
- 写入：`col.upsert`（id = `{kid}-{i}`，元数据带 kid/source/src_fid/title/seg）
- 增量：只处理 `vector_status=0`，完成后回写 1
- 单条重算：`revector_one(item_id)` 先按 kid 删旧 chunk 再重写

## 7.3 检索（com/tcm/rag/retriever.py）
`question → bge 编码 → Chroma.query(n_results=top_k) → 转成契约结构`，相似度 = 1 - cosine 距离。

## 7.4 问答（com/tcm/qa/graph.py）
```
START → retrieve（Top5）→ generate（拼提示词 → DeepSeek）→ END
```
- 拒答：`not chunks or chunks[0]["score"] < 0.5`
- 提示词四条规矩：只依据资料、句尾标 [n]、不足就拒答、提醒咨询医师
- 流式：`iter_answer` 先吐 sources，再逐 token，最后 done

## 7.5 管理端（com/tcm/rag/service.py）
统计 / 列表 / 复核门禁 / 编辑同步 / 上传秒传 / LLM 分类六大能力。
