# 03 概要设计说明书

## 3.1 系统架构
六层结构：

```
① 用户入口    static/admin  static/rag  static/qa
      ↓ HTTP
② 接入层      /api 统一前缀 · 统一响应 · def 路由 · 鉴权 · 日志
      ↓
③ 业务层      system（后台管理）  rag（知识库管理）  qa（智能体问答）
      ↓
④ 算法与模型  MD5去重 · 解析清洗 · 切片embedding · LLM分类 · 检索 · 精排(二期)
      ↓
⑤ 数据层      MySQL(库 tcm)   Chroma(tcm_knowledge)   本地文件   任务表
      ↓
⑥ 外部服务    DeepSeek LLM
```

图：`docs/图/系统架构图.svg`

## 3.2 模块划分
| 模块 | 位置 | 职责 |
|---|---|---|
| 配置 | `com/tcm/cfg/settings.py` | 统一读 .env |
| 连接池 | `com/tcm/db/conn.py` | PooledDB + 参数化 + 表名白名单 |
| ETL | `com/tcm/etl/clean.py` | 抽取清洗入库 |
| 向量化 | `com/tcm/rag/embedding.py` | 切片、批量编码、增量重算 |
| 检索 | `com/tcm/rag/retriever.py` | 语义召回 TopK |
| 管理端 | `com/tcm/rag/service.py` + `api.py` | 统计/复核/上传/分类 |
| 问答 | `com/tcm/qa/graph.py` + `api.py` | LangGraph 两节点图、SSE |
| 入口 | `com/tcm/main.py` | 路由注册、静态挂载 |

## 3.4 关键技术决策
1. **统一表 knowledge**：三源合流，`(source, src_fid)` 唯一约束保证幂等
2. **切片按语义段落**（HTML class / 【】标记），不按字数硬切
3. **本地 embedding**：bge-large-zh，零成本、可离线
4. **入库门禁**：只有已复核的知识才允许进向量库
5. **拒答机制**：最高相似度 < 0.5 直接返回"未找到"，不调用大模型
