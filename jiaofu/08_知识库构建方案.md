# 08 知识库构建方案

## 8.1 数据源
| 来源 | 条数 | 结构特点 |
|---|---|---|
| fangji | 24,870 | `<p class="drug cf/zf/gnzz/yfyl/zl">` + fieldname |
| zhongyao | 11,242 | 同上，段落为 py/ly/sjfb/gnzz/zl |
| pianfang | 1,593 | 无 class，段落用 `【标签】正文` |

## 8.2 清洗结果
输入 37,705 → 过滤 51（1 方剂 + 50 偏方，正文为空或解析不出段落）→ **入库 37,654**

## 8.3 切片策略
按语义段落切（非按字数硬切），保留段落类型，chunk 文本拼标题。
理由：清洗阶段已识别出"处方/制法/功能主治"等语义边界，切片切得好，检索准一半。

## 8.4 向量化
- 模型：本地 `bge-large-zh-v1.5`（CPU，1024 维，归一化 + cosine）
- 批量：64 段/批；实测约 0.31 条/秒
- 全量 3.7 万条约需 33 小时 → **分批后台跑 + 断点续跑**，不阻塞开发
- 增量：编辑/复核通过 → 任务表 → `revector_one` 重算该条

## 8.5 质量控制
- MD5 秒传：同文件不重复存、不重复解析
- 入库门禁：已复核才进向量库
- 幂等：唯一约束 + upsert，重跑不翻倍
