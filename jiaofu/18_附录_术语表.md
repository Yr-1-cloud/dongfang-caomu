# 18 附录 · 术语表

| 术语 | 解释 |
|---|---|
| RAG | 检索增强生成：先检索资料片段，再让大模型依据片段回答 |
| embedding | 把文本转成向量的过程/模型，本项目用本地 bge-large-zh |
| chunk | 切片：一条知识按语义段落切成若干片段，是检索的最小单位 |
| 向量库 / Chroma | 存向量并做相似度检索的数据库，本项目 collection 名 tcm_knowledge |
| TopK | 召回最相似的前 K 条片段，本项目 Top5 |
| 余弦相似度 | 向量夹角余弦值，越大越相似；本项目阈值 0.5 |
| 精排 / Rerank | 对粗召回结果重新排序，二期用 Qwen3-Reranker-0.6B |
| 幂等 | 同一操作执行多次结果一致（唯一约束 + upsert 实现） |
| 秒传 | 相同 MD5 的文件不重复存储与解析，直接返回已有条目 |
| 门禁 | 状态机约束：只有 review_status=1 的知识才允许向量化 |
| 增量同步 | 编辑一条后只重算该条向量，保证问答端同步 |
| SSE | Server-Sent Events，服务端逐段推送，用于流式回答 |
| 溯源 | 回答可反查到 source + fid + title，回到源表核对 |
| PooledDB | DBUtils 的连接池，多线程共享连接 |
