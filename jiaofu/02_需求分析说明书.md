# 02 需求分析说明书

## 2.1 用户角色
| 角色 | 诉求 |
|---|---|
| 普通用户 | 用大白话查方/查药/查偏方，要看到出处 |
| 科研人员 | 跨源检索、按栏目浏览 |
| 管理员 | 维护知识、审核入库、看统计与日志 |

## 2.2 功能需求
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-01 | 三源数据抽取清洗入统一表 | 高 |
| FR-02 | 按语义段落切片并向量化 | 高 |
| FR-03 | 自然语言语义检索（Top5 + 溯源） | 高 |
| FR-04 | 生成回答必须带引用，查不到要拒答 | 高 |
| FR-05 | 文档上传 + MD5 秒传 | 高 |
| FR-06 | 知识列表 + 统计卡片（总量/已入库/待复核/未分类） | 高 |
| FR-07 | 人工复核（通过/拒绝）+ 入库门禁 | 高 |
| FR-08 | 编辑保存后增量同步到向量库 | 高 |
| FR-09 | 问答日志落库 | 高 |
| FR-10 | LLM 辅助分类（类目+置信度+理由） | 中 |
| FR-11 | 查询改写 / 混合检索 / 精排 | 中（二期） |
| FR-12 | 意图路由、联网搜索 | 低（本期不做） |

## 2.3 非功能需求
- **合规**：只呈现知识库原文，显著免责声明，提示咨询医师
- **成本**：embedding/rerank 全本地，零 API 成本；仅生成走云端
- **可重跑**：ETL 幂等，唯一约束兜底
- **可用**：流式输出，首字延迟可控

## 2.4 约束
- 沿用既有后台管理系统与四层架构约定
- Windows 开发环境，CPU 推理
