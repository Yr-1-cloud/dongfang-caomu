## 关键坑位提醒（写代码前看一眼）

1. **路由一律 `def`**：`async def` + 同步连接池会阻塞事件循环；SSE 用同步 generator 就够
2. **批量导入走命令行**，不走 HTTP 接口（3.7 万条会超时）
3. **原始表只读**：清洗结果写 `knowledge` 新表，改规则可重跑
4. **换 embedding 模型 = 全库重建**：写进参数配置页提示
5. **`tcm_terms.txt`**（uploads/qa/）：jieba 自定义词典素材，二期上 BM25 时用
6. **`.env` / `chroma_db/` / `models/` 不要进 git**，写 `.gitignore`
