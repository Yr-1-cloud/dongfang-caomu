### 2.2 增量同步闭环（TC-14）

`uv run python docs/check/增量测试.py`

```
1. 选中知识 id=1 标题《阿魏麝香散》
2. 编辑保存：已保存并同步到向量库（问答端立即可查）
3. 用标记检索：召回 5 条，命中目标：True
4. 问答端回答包含新内容：True
   回答开头：根据资料，阿魏麝香散【增量测试标记XYZ】的功能主治为：肠覃、诸积、痞块 [3]。
5. 已还原原标题，标记不再被召回：True
结论：✅ 通过（编辑 → 向量更新 → 问答同步 全链路打通）
```

> 踩坑记录：第 4 步最初用纯生造标记词提问，因语义相似度低于 0.5 被拒答机制拦截。
> 这恰恰**反证了拒答阈值在正常工作**；调整问法（带上真实方名）后通过。

### 2.3 入库门禁（TC-12 / TC-13）

```
新知识上传后：review_status=0（待复核）、vector_status=0（未入库）
此时触发保存：{'msg': '已保存，但未复核，暂不进向量库', 'vectorized': False}
人工点击"通过"：{'msg': '已通过并向量化'}
复核后状态：review_status=1、vector_status=1
```
