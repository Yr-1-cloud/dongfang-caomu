# 04 数据库设计说明书

库：`tcm`（MySQL 8.0，utf8mb4）

## 4.1 knowledge（统一知识表）★核心

```sql
CREATE TABLE knowledge (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    source          VARCHAR(32)  NOT NULL COMMENT 'fangji/zhongyao/pianfang/doc',
    src_fid         VARCHAR(64)  NOT NULL COMMENT '源表主键，溯源用',
    title           VARCHAR(255)     DEFAULT '',
    content         MEDIUMTEXT                  COMMENT '清洗后正文（每行一段：标签：文本）',
    category        VARCHAR(128)     DEFAULT '',
    summary         VARCHAR(1000)    DEFAULT '' COMMENT '优先取功能主治',
    keywords        VARCHAR(500)     DEFAULT '',
    review_status   TINYINT      NOT NULL DEFAULT 0 COMMENT '0待复核 1已复核 2已拒绝',
    vector_status   TINYINT      NOT NULL DEFAULT 0 COMMENT '0未入库 1已入库',
    confidence      TINYINT               DEFAULT NULL COMMENT 'LLM分类置信度',
    classify_reason VARCHAR(500)          DEFAULT NULL,
    state           TINYINT      NOT NULL DEFAULT 1,
    isDel           TINYINT      NOT NULL DEFAULT 0,
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    UNIQUE KEY uk_source_fid (source, src_fid),
    KEY idx_review (review_status),
    KEY idx_vector (vector_status),
    KEY idx_category (category)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**设计要点**
- `uk_source_fid` 是幂等的命根子：重跑不插重
- `content` 用 MEDIUMTEXT（TEXT 上限 65535 字节不够）
- `review_status` + `vector_status` 双状态：一个管"人审没审"，一个管"进没进向量库"
- 不建 FULLTEXT：检索走向量，不用 LIKE
