# 12 部署手册

## 12.1 环境
Windows + Python 3.14 + MySQL 8.0 + uv

## 12.2 步骤
```bash
# 1) 安装依赖
uv sync

# 2) 配置 .env（数据库 + 大模型）
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=***
DB_NAME=tcm
DEEPSEEK_API_KEY=sk-***
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL_CHAT=deepseek-chat

# 3) 建库建表
mysql -u root -p < sql/01_tcm_schema.sql

# 4) 下载模型
uv run python -c "from modelscope import snapshot_download; snapshot_download('BAAI/bge-large-zh-v1.5', local_dir='models/BAAI--bge-large-zh-v1.5')"

# 5) 清洗入库
uv run python -m com.tcm.etl.clean

# 6) 向量化（分批，可反复跑）
uv run python -m com.tcm.rag.embedding --limit 500

# 7) 启动
uv run uvicorn com.tcm.main:app --port 8000
```

## 12.3 访问
- 问答页 http://127.0.0.1:8000/qa/
- 管理页 http://127.0.0.1:8000/rag/
- 健康检查 http://127.0.0.1:8000/api/health

## 12.4 注意事项
- 模型路径默认 `models/BAAI--bge-large-zh-v1.5/snapshots/master`
- 换 embedding 需全库重建向量
