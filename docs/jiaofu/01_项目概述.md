# 01 项目概述

## 1.1 项目背景
中医药资料分散在方剂、药材、偏方三类数据源中，传统关键词检索难以表达"治痞块的方子"这类自然语言诉求。本项目构建**三源合一的中医药知识库 + 带出处的跨源智能问答**。

## 1.2 项目目标
- 把 3.7 万条异构数据清洗成统一知识表
- 提供语义检索 + LLM 生成，回答**必须带引用出处**
- 通过状态机与人工复核管住入库质量

## 1.3 范围
| 子系统 | 内容 | 状态 |
|---|---|---|
| 知识库构建（RAG） | 清洗、切片、向量化、管理端 | 已完成 |
| 智能体问答（QA） | 检索、LangGraph 生成、流式问答页 | 已完成 |
| 后台管理（system） | 用户/角色/菜单/日志等 | 沿用既有交付 |

## 1.4 技术栈
Python 3.14 + FastAPI + PyMySQL/DBUtils + LangChain/LangGraph + Chroma + 本地 bge-large-zh + DeepSeek + 原生 HTML/JS（Bootstrap/axios，无构建工具）。

## 1.5 关键指标
- 知识总量 37,654 条（方剂 24,869 / 药材 11,242 / 偏方 1,543）
- 召回测试 10/10 命中 Top5
- 测试用例 15/15 通过
