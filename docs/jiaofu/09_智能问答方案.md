# 09 智能问答方案

## 9.1 链路
```
提问 → 本地 embedding → Chroma Top5 → 阈值判定 → 拼提示词 → DeepSeek → SSE 流式 → 引用列表
```

## 9.2 LangGraph 图
两节点 `retrieve → generate`，State = `{question, chunks, answer}`。

## 9.3 拒答机制（关键）
最高相似度 < 0.5 → 直接返回"知识库中没有找到相关内容"，**不调用大模型**。
实测：问"今天北京天气怎么样"相似度 0.29，正确拒答。

## 9.4 引用与溯源
提示词要求句尾标 `[n]`；前端列出每个片段的 `source / fid / title / 段落类型 / 相似度`，可按 fid 回源表核对。

## 9.5 流式
`def` 路由 + 同步 generator + `StreamingResponse`，事件类型 sources/token/done/error。

## 9.6 医疗合规
提示词强制"涉及用药提醒咨询医师"，页面显著免责声明。
