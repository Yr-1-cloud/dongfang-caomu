# 13 用户操作手册

## 13.1 智能问答（/qa/）
1. 打开 http://127.0.0.1:8000/qa/
2. 输入自然语言问题，如"治痞块用什么方"，回车或点提问
3. 回答逐字显示，下方"引用片段"列出来源方剂/药材与相似度
4. 库里没有的内容会明确提示"知识库中没有找到相关内容"

## 13.2 知识库管理（/rag/）
- **顶部卡片**：知识总量 / 已进向量库 / 待复核 / 未分类
- **筛选**：按来源、复核状态、向量状态、标题关键词
- **复核**：点"通过"→ 自动向量化；点"拒绝"→ 不进向量库
- **编辑**：改标题或正文后保存，自动同步向量库（问答端立即可查）
- **分类**：点"分类"由 LLM 打标签，置信度 ≥80 自动通过复核
- **上传**：选文件上传，同文件重复上传会提示"秒传成功，未重复解析"

## 13.3 免责声明
系统仅呈现知识库原文，不构成诊疗建议，用药请咨询专业医师。
