# 10 测试计划

## 10.1 测试范围
清洗入库、向量化、检索、问答、管理端、增量同步。

## 10.2 测试方法
| 类型 | 方法 | 工具 |
|---|---|---|
| 数据测试 | 行数核对、去重校验、抽查清洗效果 | SQL + 清洗报告 |
| 召回测试 | 10 个自然语言问题，目标进 Top5 | `com/tcm/rag/test_recall.py` |
| 功能测试 | 上传/复核/编辑/分类 | 接口 + 页面 |
| 闭环测试 | 改一条 → 问答端查到新内容 | `docs/check/增量测试.py` |
| 异常测试 | 库外问题拒答、重复上传秒传 | 手工 + 脚本 |

## 10.3 通过标准
- 召回测试命中 ≥ 8/10
- 测试用例通过率 100%
- 增量闭环全绿

## 10.4 测试环境
Windows + Python 3.14 + MySQL 8.0 本机 + Chroma + 本地 bge-large-zh + DeepSeek API
