# 05 接口设计说明书

统一前缀 `/api`，统一响应 `{code, msg, data}`；全部用 `def`（同步路由，连接池是同步的）。

## 5.1 问答
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/qa/ask` | SSE 流式问答，事件 `data: {"type":"sources"|"token"|"done"|"error","data":...}` |
| GET | `/api/qa/logs?limit=10` | 最近问答日志 |

请求体：`{"question": "治痞块用什么方"}`

## 5.2 知识库管理
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/rag/stats` | 四张统计卡片：total / vectorized / pending_review / unclassified |
| GET | `/api/rag/list?page&size&source&review_status&vector_status&keyword` | 分页列表 |
| GET | `/api/rag/detail?id=` | 单条详情 |
| POST | `/api/rag/review` | `{"id":1,"action":"pass"|"reject"}` |
| POST | `/api/rag/edit` | `{"id":1,"title":"","content":""}` 保存并增量同步 |
| POST | `/api/rag/upload` | multipart 文件上传（MD5 秒传） |
| POST | `/api/rag/classify` | `id`，LLM 分类 |
| GET | `/api/rag/tasks?limit=20` | 任务表 |

## 5.3 三个冻结契约（开工前确定）
1. **knowledge 表结构**：见《04 数据库设计说明书》
2. **检索函数签名**：`search(question, top_k=5) -> [{"source","fid","title","seg","text","score"}]`
3. **QA State**：`{"question": str, "chunks": list, "answer": str}`

## 5.4 错误码
| code | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 业务失败（记录不存在、参数错误），msg 带原因 |
