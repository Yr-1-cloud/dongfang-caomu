# 16 风险评估与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 导入超时 | 3.7 万条写入卡死 | 命令行分批 + executemany，不走 HTTP |
| HTML 残留 | 检索质量下降 | 按 class / 【】提取 + 清洗报告抽查 |
| 术语不统一 | 召回偏差 | 本期不归一，靠原文 + 引用 |
| 向量化耗时长 | 覆盖率不足 | 分批后台跑、断点续跑、可换 GPU |
| 模型幻觉 | 医疗合规风险 | 只依据片段 + 阈值拒答 + 免责声明 |
| Windows DLL 冲突 | 进程段错误难排查 | 固定导入顺序：先 torch 后 langchain |
| 联调返工 | 返工成本 | 接口契约先行冻结 |

## 应急预案
- 数据出问题：源表只读，随时重跑 ETL
- 向量库损坏：从 knowledge 重建（脚本幂等）
- API 额度：生成走云端，embedding 本地不受影响
